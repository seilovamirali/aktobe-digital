# Цифровизация Актюбинской области

Статический сайт о том, как Актюбинская область развивает связь, государственные услуги, медицину, образование и аналитику.

Факты и цифры взяты только с официального сайта акимата на портале [gov.kz](https://www.gov.kz/org/aktobe?lang=ru): страницы акимата Актюбинской области и управления цифровых технологий. У каждого показателя на сайте есть дата публикации и ссылка. Дата сбора материалов — 5 ноября 2026 года.

Сайт публикуется через GitHub Pages из корня ветки `main`: <https://seilovamirali.github.io/aktobe-digital/>.

Откройте `index.html` в браузере. Сборка не нужна.
